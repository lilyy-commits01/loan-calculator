# Loan Calculator

A small, beginner-friendly web tool that shows the monthly payment, total cost and total interest of a loan.

**Live demo:** _add your GitHub Pages link here_

## Run it

Open `index.html` in your browser. No install needed.

## How it works

```
monthly payment = P × r / (1 − (1 + r)^−n)
```

- `P` is the loan amount
- `r` is the monthly rate (yearly rate ÷ 12)
- `n` is the number of months

Quick check: 10,000 at 5% over 12 months gives 856.07 per month.
